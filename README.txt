========================================
  EarnBot — পয়েন্ট আর্নিং Telegram বট
========================================

⚠️  Bot Token কখনো প্রকাশ্যে শেয়ার করবেন না!
    BotFather → /revoke দিয়ে পুরনো token বাতিল করুন।

────────────────────────────────────────
ধাপ ১: Python ইনস্টল করুন (3.10+)
────────────────────────────────────────
https://www.python.org/downloads/

────────────────────────────────────────
ধাপ ২: PostgreSQL ডেটাবেস তৈরি করুন
────────────────────────────────────────
psql -U postgres -c "CREATE DATABASE earnbot;"
psql -U postgres -d earnbot -f schema.sql

────────────────────────────────────────
ধাপ ৩: .env ফাইল তৈরি করুন
────────────────────────────────────────
.env.example ফাইলটি কপি করুন:
  cp .env.example .env

তারপর .env ফাইলে আপনার তথ্য বসান:
  TELEGRAM_BOT_TOKEN=আপনার_টোকেন
  DATABASE_URL=postgresql://user:pass@localhost/earnbot
  TELEGRAM_ADMIN_CHAT_ID=আপনার_চ্যাট_আইডি (ঐচ্ছিক)

────────────────────────────────────────
ধাপ ৪: নির্ভরতা ইনস্টল করুন
────────────────────────────────────────
pip install -r requirements.txt

────────────────────────────────────────
ধাপ ৫: বট চালু করুন
────────────────────────────────────────
একবার চালাতে:
  python bot.py

সবসময় চালু রাখতে (Linux/Mac):
  chmod +x run.sh
  ./run.sh

সার্ভারে background-এ চালাতে:
  nohup ./run.sh > bot.log 2>&1 &

────────────────────────────────────────
বট ফিচার:
────────────────────────────────────────
• চ্যানেল সদস্যতা যাচাই
• মোবাইল নম্বর দিয়ে লগইন
• গেম খেলে পয়েন্ট আয় (+৩০)
  - কয়েন ফ্লিপ
  - নম্বর অনুমান (১-৫)
  - রঙ বেছে নেওয়া
• বিজ্ঞাপন দেখে পয়েন্ট (+৪০)
• বিকাশ/নগদে উইথড্র
• লিডারবোর্ড
• ব্যক্তিগত স্ট্যাটস
• অ্যাডমিন নোটিফিকেশন
